### Instructions for using specific subbranch of AtomTwin.jl
Always start by activating the virtual environment. Enter the julia REPL then go to the ```pkg```REPL by entering ```]```.

Next enter ```dev ~<path to AtomTwin directory>```

This way, this project will always track the local branch of AtomTwin which is checked out on this computer.
